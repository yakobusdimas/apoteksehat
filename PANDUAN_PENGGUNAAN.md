# 🏥 Apotek Sehat - Sistem Rekomendasi Obat Berbasis AI

## 📋 Deskripsi
Website e-commerce apotek dengan fitur AI Chatbot untuk rekomendasi obat berdasarkan gejala pengguna. Dilengkapi dengan dashboard admin untuk manajemen stok dan dashboard user untuk belanja obat online.

## ✨ Fitur Utama

### 🌐 Landing Page (Tanpa Login)
- Preview 10 obat dengan informasi lengkap

- **Floating AI Chatbot** di pojok kanan bawah untuk konsultasi gejala

- ✅ Riwayat pesanan
- ✅ Favorit obat

### 👨‍💼 Dashboard Admin (Tema Biru)
**Login sebagai Admin untuk kelola apotek:**
- ✅ Manajemen stok obat (tambah/kurang stok)
- ✅ Update stok secara live
- ✅ Monitoring stok rendah
- ✅ Riwayat pembelian semua user

## 🤖 Cara Menggunakan AI Chatbot

### 1. Dari Landing Page
- Klik **tombol chatbot** yang melayang di pojok kanan bawah
- Ketik gejala yang dialami (contoh: "saya demam", "batuk", "flu")
- AI akan merekomendasikan obat dari **termurah ke termahal**
- Untuk membeli, silakan login terlebih dahulu

### 2. Setelah Login (User Dashboard)
- Chatbot tetap tersedia di pojok kanan bawah
- Klik obat yang direkomendasikan untuk langsung menambah ke keranjang
- Lanjutkan ke checkout

### Contoh Konsultasi dengan AI:
```
User: "Saya demam dan sakit kepala"
AI: "Untuk gejala demam, saya merekomendasikan:
     1. Bodrex - Rp 7.000
     2. Paracetamol 500mg - Rp 15.000"

User: "Saya batuk berdahak"
AI: "Untuk gejala batuk, berikut rekomendasinya:
     1. Komix Herbal - Rp 5.000
     2. OBH Combi Sirup - Rp 18.000"
```

## 🛒 Alur Belanja Online

### 1. **Browse Obat** (Landing Page)
   - Lihat katalog 10 obat
   - Gunakan filter kategori atau search
   - Konsultasi dengan AI Chatbot

### 2. **Login/Register**
   - Klik "Masuk" atau "Daftar"
   - Isi formulir pendaftaran

### 3. **Belanja di Dashboard User**
   - Pilih obat
   - Klik "Tambah ke Keranjang"
   - Lihat keranjang di tab "Keranjang"

### 4. **Checkout**
   - Isi alamat pengiriman
   - Pilih kurir (JNE, J&T, SiCepat)
   - Pilih metode pembayaran
   - Gratis ongkir untuk pembelian ≥ Rp 100.000

### 5. **Tracking Paket**
   - Otomatis redirect ke halaman tracking
   - Lihat status pengiriman real-time
   - Timeline: Pesanan Dibuat → Dikemas → Dikirim → Dalam Perjalanan → Sampai

## 💡 Tips Penggunaan

### Untuk User:
1. **Gunakan AI Chatbot** sebelum belanja untuk mendapat rekomendasi tepat
2. **Cek promo gratis ongkir** untuk pembelian ≥ Rp 100.000
3. **Simpan nomor pesanan** untuk tracking paket
4. **Pilih kurir tercepat** jika obat dibutuhkan segera

### Untuk Admin:
1. **Monitor stok rendah** (warna orange) untuk restock
2. **Update stok secara berkala** agar selalu tersedia
3. **Gunakan fitur pencarian** untuk cepat temukan obat
4. **Pantau riwayat pembelian** untuk analisis penjualan
